# Kaung — portfolio (CV)

Public site that renders my curriculum vitae as a printable page. Built with Next.js and Tailwind CSS.

## Scripts

- `npm run dev` — local preview at http://localhost:3000
- `npm run build` — production build
- `npm run start` — serve the production build

## Structure

- `app/page.tsx` — CV content and in-page anchor links
- `app/layout.tsx` — document shell and metadata
- `app/globals.css` — typography and print styles
